# ИнСайт — управляемый чат-бот для веб-студии

Рабочая демонстрация чат-бота для сбора брифа веб-студии. Пользователь проходит только релевантную ветку, оставляет контакты и получает предварительный диапазон стоимости. Заказчик меняет тексты, вопросы, варианты ответов и контакты в админ-панели без работы с кодом.

## Реализовано

- блок конфиденциальности перед началом;
- главное меню с пятью направлениями;
- отдельные сценарии нового сайта, доработки и продвижения;
- условные шаги для товаров, услуг и смешанного каталога;
- одиночный и множественный выбор, свободный ввод и загрузка ТЗ;
- портфолио по сферам и контактный раздел;
- финальный сбор имени, телефона, мессенджера и удобного времени;
- сохранение заявок через Node.js API;
- адаптивная вёрстка для телефона и компьютера;
- автоматическое сохранение незавершённого брифа.

## Дополнительная функция

После заполнения бот формирует предварительный диапазон стоимости на основе выбранных функций и сложности проекта. Это даёт клиенту ориентир до созвона, а менеджеру — структурированный бриф. Расчёт явно отмечен как предварительный.

## Администрирование

Кнопка «Админ-панель» открывает интерфейс, где можно менять:

- название студии, имя ассистента, приветствие и текст конфиденциальности;
- Telegram, телефон и email;
- формулировки всех вопросов и подсказок;
- варианты ответов каждого шага.

После сохранения обновления применяются к демо. Сервер хранит конфигурацию и заявки в каталоге `data`, который не публикуется в Git.

## Запуск

```bash
npm install
npm run dev
```

Демо: `http://localhost:5173`  
Админ-панель: `http://localhost:5173/?admin=1`

Для production:

```bash
npm run build
npm start
```

Production-сервер откроется на `http://localhost:4173`.

## Технологии и расходы

React, Vite, Node.js, Express. Платной платформы и абонентской платы нет. После запуска остаётся только хостинг — ориентировочно 500–1000 ₽ в месяц в зависимости от провайдера и нагрузки.

Оценка разработки такого решения для реального проекта: 120 000–180 000 ₽ с учётом финальной настройки контента, подключения уведомлений, домена и размещения.
